# Support

Aetheris OS is an experimental project without a supported end-user release.

- Use [GitHub Discussions](https://github.com/amandeavor/Aetheris-OS/discussions) for design questions, development setup, and general ideas.
- Use the issue forms for reproducible bugs and scoped feature proposals.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Please do not rely on Aetheris for important systems or data. If you experiment with installation or system configuration, use a disposable virtual machine and keep independent backups.
